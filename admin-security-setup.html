Admin Security Setup

One-time setup helper

Do not publish the portal for real athlete use until the Firestore and Storage rules are deployed and the admin email placeholder is replaced.
  1. Choose the Google account that only you control for athletics administration.
  2. Replace REPLACE_WITH_YOUR_ADMIN_GOOGLE_EMAIL in js/firebase-config.js, firestore.rules, and storage.rules.
  3. Enable Google and Email/Password providers in Firebase Authentication.
  4. Create Firebase Storage and deploy storage.rules.
  5. Deploy firestore.rules.
  6. Then sign in through login.html with the admin Google account.
